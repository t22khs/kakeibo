# 家計簿（オフライン対応PWA）

スマホのホーム画面から起動でき、電波がなくても使える家計簿です。
データはスマホの中（IndexedDB）にだけ保存され、どこにも送信されません。

## できること
- **帳簿の切り替え**（初期設定は「家計」と「自分」。名前は設定で変更可）。予算・カテゴリは帳簿ごと、色も帳簿ごとに変わる
- 支出・収入の記録（金額・カテゴリ・日付・メモ）。記録をタップで編集・削除
- **帳簿ごとの残高**（いまの残高を一度設定すれば、記録に合わせて自動で増減。過去の月は月末時点の残高を表示）
- 月ごとの収入・支出・収支
- 毎月の予算と残額（今月は「1日あたりいくら使えるか」も表示）
- カテゴリ別の支出グラフ
- CSVの書き出し／読み込み（全帳簿まとめて。Excel対応、重複は自動でスキップ）
- カテゴリの追加・整理、ダークモード対応

## ファイル構成
```
index.html             画面
style.css              見た目
app.js                 動き・データ保存
sw.js                  オフライン対応（Service Worker）
manifest.webmanifest   ホーム画面アイコンの設定
icon-*.png, apple-touch-icon.png  アイコン画像
```

## GitHub Pagesで公開する（無料・約10分）
PCで作業するのが簡単です。

1. https://github.com でアカウントを作成（無料）
2. 右上の「＋」→「New repository」。名前は `kakeibo` など、**Public** を選んで作成
3. 作成後の画面で「uploading an existing file」をクリックし、このフォルダの中身を**フォルダごと**ドラッグ＆ドロップ →「Commit changes」
4. リポジトリの「Settings」→ 左メニュー「Pages」→ Branch を `main` / `/(root)` にして「Save」
5. 1〜2分待つと `https://<ユーザー名>.github.io/kakeibo/` で開けるようになります

※ Publicでも公開されるのはアプリのプログラムだけです。家計のデータは各自のスマホの中にあり、GitHubには載りません。

## スマホのホーム画面に追加
上のURLを一度開いてから：
- **iPhone**：Safariで共有ボタン →「ホーム画面に追加」
- **Android**：Chromeの︙メニュー →「ホーム画面に追加」（または「アプリをインストール」）

一度開けば、以降はオフラインでも起動できます。

## 大事な注意
- データはその端末・そのブラウザの中だけにあります。**月に1回くらい「設定 → CSVで書き出す」でバックアップ**してください。機種変更時は新しいスマホで「CSVを読み込む」で戻せます。
- iPhoneでは「ホーム画面のアイコン」と「Safariで開いたページ」でデータが別々になります。ホーム画面から使うようにしてください。
- ブラウザの「履歴とWebサイトデータを消去」をするとデータも消えます。

## アプリを更新するとき
ファイルを書き換えてGitHubにアップロードしたら、`sw.js` の `CACHE = 'kakeibo-v3'` の数字を上げてください（v2, v3…）。次にアプリを開いたとき（または2回目に開いたとき）に新しい版に切り替わります。
